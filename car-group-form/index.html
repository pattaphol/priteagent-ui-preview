01 · ช่วงเวลาและรหัสคันรถ

แสดงฟิลด์แบบ V1 แต่ไม่ออกรหัสและไม่ปรับวันที่อัตโนมัติ

รหัสคันรถ GRP-IDGRP-DEMO-XXXX

ตัวอย่างคงที่เท่านั้น ไม่ใช่รหัสสำหรับเข้าร่วมคันรถ

V1 มีตัวเลือกวันที่ตามวีค (จันทร์–ศุกร์) แต่ต้นแบบนี้ให้เลือกวันที่เอง ไม่มีการคำนวณช่วงวันตามกฎ V1

02 · ข้อมูลคันรถ

ชื่อ จังหวัด และหมายเหตุพื้นที่/งาน ตามภาพ V1

ไม่ควรกรอกข้อมูลลูกค้าหรือสถานที่จริงใน Preview

03 · สมาชิกและบทบาท

รายชื่อสมมติ คนที่ 1–4 และแยก CarLeader ออกจาก CarOwner

ใช้ควบคุมช่องในหน้าทดลอง ไม่ใช่สิทธิ์สมาชิกจริง
1คนที่ 1หัวหน้าคัน
2คนที่ 2เจ้าของรถ
3คนที่ 3เจ้าของรถ
4คนที่ 4เจ้าของรถ
เฉพาะการแสดงผล ไม่ผูกบัญชีและไม่เปลี่ยนสิทธิ์จริง
หัวหน้าคัน · CarLeaderสมาชิก 1คนที่ 1 (ตัวอย่าง)
เจ้าของรถ · CarOwnerสมาชิก 3คนที่ 3 (เลือกได้)
บทบาท: คนที่ 1 เป็นหัวหน้าคันตามกรอบ Owner-approved ตัวอย่างนี้ให้เลือกเจ้าของรถแยกกัน ไม่มีการตั้งสิทธิ์สมาชิกหรือเชื่อมบัญชีจริง

04 · ตรวจทานและข้อมูลเพิ่มเติม

งบประมาณและสกุลเงินเป็นเพียงตัวอย่าง ไม่มีการบันทึกหรือคำนวณเงินจริง

ข้อมูลสาธิต ไม่ตรวจจำนวนเงินและไม่ใช้กับ Expense
แสดงผลเท่านั้น ไม่มีระบบสกุลเงินจริง
ข้อมูลการคิดค่าน้ำมันยังไม่คำนวณ — รอ Owner ยืนยันกฎ V2ไม่คัดลอกเปอร์เซ็นต์จาก V1 และไม่สร้างสูตรใหม่ใน UI
ขอบเขต: ดูตัวอย่างข้อมูลเท่านั้น ไม่มี Save / Business Calculation / Auth / Backend / API
